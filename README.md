# 建设主题

建设主题是一款适用于 SillyTavern（酒馆）的中文界面扩展。手机使用底部导航，电脑使用侧栏。支持浏览角色、继续聊天、管理面具、世界书和预设，也可以为每个聊天存档单独选择预设与模型。

## 安装与启用

1. 打开酒馆的「扩展」面板，点「安装扩展」。
2. 粘贴仓库地址 `https://github.com/krystalqiye-lj/jianshe-zhuti`，确认安装，然后刷新酒馆。
3. 打开酒馆的「用户设置」，在「界面主题」区域点「启用建设主题」。已经使用星间舱室的用户，也可以从「舱室设置」启用。

最低支持 SillyTavern 1.12.14。已在 1.12.14 和 1.13.0、1.14.0、1.15.0、1.16.0、1.17.0、1.18.0、1.19.0 的基础酒馆测试电脑和手机布局。手机布局采用触屏模拟测试。过去通过酒馆助手全局脚本使用这套界面的用户，请先停用旧脚本并刷新，再启用扩展。使用同一酒馆账号时，主题会读取原有偏好和存档设置。

已有旧版时，在酒馆的扩展管理里找到「建设主题」，点更新，再刷新页面。手动安装的用户可把新版压缩包里的全部文件覆盖到原扩展目录。

较早版本的酒馆按服务商共用密钥。在「模型连接」里留空会沿用已保存的密钥，填写新值会更新该服务商所有连接使用的密钥。

## 切回原界面

手机点底部「我的」，电脑点侧栏「设置」，在「数据与主题」里点「切回原主题」。以后可以在原界面的同一位置重新启用。要彻底停用扩展，切回后打开酒馆的扩展管理，关闭「建设主题」并刷新。

## 聊天与记忆

从首页点角色卡会继续这个角色最近一次打开的旧存档。只看开场白时会保留预览，发送第一条用户消息后才在主题的存档列表与数量中计入。从「我的角色」点卡片可以编辑角色资料。聊天中打开预设和模型选择器，点各栏标题旁的放大镜可以搜索预设或模型。在两栏各选一项后确认，这个聊天存档会记住搭配。

聊天右上角的小喇叭控制当前页面的声音。静音时，角色卡的音乐可以继续走进度。再点一次恢复声音，已暂停的曲目会继续暂停。同一标签页刷新后会记住开关。独立外站嵌入的播放器可能需要用它自己的静音键。

在「世界书」的「全局世界书设置」中，可以搜索书名，勾选要在所有聊天中启用的书。可以全部留空，各角色仍使用各自绑定的世界书。

从聊天工具箱进入「故事记忆」，可以编辑当前存档的手动记忆。安装并启用柏宝书后，还可以在这里查看和编辑它生成的摘要。点标题旁的问号可以查看两种记忆的用途。

## 手动安装

将「建设主题.zip」解压，把里面含有 `manifest.json` 的整个文件夹放入酒馆的 `data/default-user/extensions/`。多用户酒馆请使用自己账号对应的目录。刷新后按上面的步骤启用。
