# 建设主题

建设主题是 SillyTavern（酒馆）制作的中文界面扩展。手机使用底部导航，电脑使用侧栏。支持浏览角色、继续聊天、管理面具、世界书和预设，也可以为每个聊天存档单独选择预设与模型。

## 安装与启用

1. 打开酒馆的「扩展」面板，点「安装扩展」。
2. 粘贴仓库地址 `https://github.com/krystalqiye-lj/jianshe-zhuti`，确认安装，然后刷新酒馆。
3. 打开酒馆的「用户设置」，在「界面主题」区域点「启用建设主题」。已经使用星间舱室的用户，也可以从「舱室设置」启用。

使用基础酒馆即可。适配版本为 SillyTavern 1.19.0。过去通过酒馆助手全局脚本使用这套界面的用户，请先停用旧脚本并刷新，再启用扩展。使用同一酒馆账号时，主题会读取原有偏好和存档设置。

## 切回原界面

手机点底部「我的」，电脑点侧栏「设置」，在「数据与主题」里点「切回原主题」。以后可以在原界面的同一位置重新启用。要彻底停用扩展，切回后打开酒馆的扩展管理，关闭「建设主题」并刷新。

## 聊天与记忆

从首页点角色卡可以继续聊天。从「我的角色」点卡片可以编辑角色资料。聊天中打开预设和模型选择器，在两栏各选一项后确认，这个聊天存档会记住搭配。

从聊天工具箱进入「故事记忆」，可以编辑当前存档的手动记忆。安装并启用柏宝书后，还可以在这里查看和编辑它生成的摘要。点标题旁的问号可以查看两种记忆的用途。

## 手动安装

将「建设主题.zip」解压，把里面含有 `manifest.json` 的整个文件夹放入酒馆的 `data/default-user/extensions/`。多用户酒馆请使用自己账号对应的目录。刷新后按上面的步骤启用。
